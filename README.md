# 🚀 My Portfolio Website

A modern, responsive portfolio website showcasing my expertise as a **Senior AI/ML Engineer** — featuring sections for About, Expertise, Technical Stack, Projects, and Contact.  
Optimized for both **desktop and mobile** with a clean UI built using modern web technologies.

---

## 📁 Project Overview

This project highlights:
- My professional summary and technical expertise
- Skills across AI/ML, Cloud, DevOps, and Full Stack tools
- Interactive UI with optimized mobile experience
- Dynamic GitHub project section

---

## 🧠 Tech Stack

Built using:
- ⚛️ **React + TypeScript**  
- 💨 **Vite + Tailwind CSS**  
- 🧱 **shadcn/ui** for modern, accessible components  
- 📱 Fully responsive design  

---

## 🛠️ Getting Started (Local Setup)

Follow the steps below to run the portfolio locally:

```bash
# Step 1: Clone the repository
git clone <YOUR_GIT_REPO_URL>

# Step 2: Navigate into the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Run the development server
npm run dev
